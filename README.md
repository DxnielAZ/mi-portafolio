# Portafolio - Jose Daniel Rodelo Naizzir

## Cómo abrirlo en VS Code
1. Descomprime la carpeta y ábrela en VS Code (Archivo > Abrir carpeta).
2. Instala la extensión "Live Server" y haz clic derecho en `index.html` > "Open with Live Server".
   (También puedes abrir `index.html` directamente en el navegador.)

## Estructura
- `index.html`: la página.
- `css/estilos.css`: colores (modo claro y oscuro) y estilos propios.
- `js/tailwind-config.js`: configuración de Tailwind (colores y fuentes).

## Importante
Tailwind y las fuentes se cargan desde internet (CDN), así que necesitas conexión
para que se vea bien. Para usar Tailwind sin internet, instala la CLI con Node.js.
